# Anonymity Analyzer Pro 🛡️

**Anonymity Analyzer Pro** — bu foydalanuvchining tarmoqdagi anonimlik darajasini tahlil qilish va tizim xavfsizligini tekshirish uchun mo'ljallangan Python dasturi.

## ✨ Asosiy funksiyalari
* **IP tahlili:** Haqiqiy IP manzil va VPN/Tor ulanishlarini aniqlash.
* **Tizim auditi:** Qurilma va operatsion tizim haqidagi ochiq ma'lumotlarni tekshirish.
* **OSINT skanerlash:** Ochiq manbalar orqali ma'lumotlar sizib chiqishini tahlil qilish.
* **Xavfsizlik reytingi:** Umumiy anonimlik darajasini ballarda hisoblash.
